### English security summary

An administration received several emails from a source that seemed to be from the internal IT-support group, the emails were considered eloquent and seemed credible, in these emails users were asked to click a link to login to retain their access rights to the internal system. Only after a user clicked the link did the suspicion of phishing arise.
If this is a phishing attempt then that could expose important assets such as account credentials.


CIS Access control was deemed the top control because stronger access controls like MFA could reduce the threat impact substantially.


At present the intent of the email is not confirmed and whether AI was used to generate it or not, but since the user has interacted with the link the possibility whether the intent was malicious or not can not be ruled out, and should be investigated more thoroughly to assure no vulnerabilities were exploited.
